# 문장별 본문 빈칸 시험

제공된 본문을 사람이 읽고 실제 문장 단위로 나눈 뒤, 밑줄·형광 표시·문법 주석을
우선하여 고른 핵심 표현을 빈칸으로 만들었습니다. 문장마다 한두 곳의 표현을 고르며
여러 단어 구문은 단어마다 입력칸을 표시합니다.

- Lesson 5: 25문장 (첨부 `5-6과.pdf`의 실제 내용은 Lesson 5뿐입니다.)
- Lesson 7: 28문장 (단독 인사 `Hi.`를 제외한 본문 문장)
- Lesson 8: 41문장
- 합계: 94문장, 247빈칸. Lesson 6은 자료를 받기 전까지 비활성 상태입니다.

## 문장 구분

번호나 화면 줄 바꿈을 문장 경계로 사용하지 않습니다.
Lesson 7의 자료 13번 자기소개와 다음 문장, 24번의 명령문과 의문문은 각각 나눴습니다.
Lesson 8의 자료 6번과 27번은 두 실제 문장으로 나눴고, 34~35번은 발화 도입부와
인용문이 이어지는 한 문장이므로 합쳤습니다. 물음표나 느낌표 뒤에 이어지는
`she thought`, `shouted Goldilocks` 같은 발화 보고절은 해당 인용문과 함께 유지합니다.
여러 문장에 걸친 인용문의 따옴표만 개별 문항에서 짝이 맞도록 정리했습니다.
제목·인물명 표제·별도 문법 설명은 문제로 출제하지 않습니다.

## 데이터 수정

`source.json`이 편집 원본입니다. `marked`에서 `[[in front of]]`처럼 표현을 표시하면
단어별 빈칸 세 개와 정답 배열이 생성됩니다. `translation`, `explanation`, 원문 번호,
PDF 페이지 및 교재 쪽수를 함께 보관합니다. 원본 PDF 파일은 저장소에 복사하지 않습니다.

```powershell
node scripts/build-reading-cloze.mjs
```

생성되는 `questions.json`과 `answers.json`을 시험에서 읽습니다. Lesson별 문장 ID는
고정되어 있어 나중에 Lesson 6을 추가하더라도 다른 단원의 저장 답안을 바꾸지 않습니다.

## 학습 및 채점

시작 화면에서 단원과 본문 순서/무작위 출제를 고릅니다. 기본은 본문 순서입니다.
답안·진행 위치·선택 단원·출제 순서는 시험별로 저장하고 이어 풀기에 복원합니다.
해석은 처음부터 언제든 볼 수 있고 점수 감점은 없습니다.
빈칸별로 1점씩 채점하고 일부만 맞힌 문장에는 부분 정답과 부분 점수를 표시합니다.
답안을 수정하면 이전 채점 표시와 원문 정답은 감춥니다. 펼친 해석은 계속 유지합니다.
Enter는 다음 칸으로 이동하며 마지막 칸에서는 정답을 확인합니다.

대소문자, 앞뒤/연속 공백과 작은따옴표 모양(`’`/`'`)은 구분하지 않습니다.
철자·시제·단복수와 원문의 축약 형태는 정확히 써야 합니다. 동의어나 임의의 표현을
정답으로 추가하지 않습니다. 정답확인 뒤에는 완성된 원문과 핵심 설명을 표시합니다.
