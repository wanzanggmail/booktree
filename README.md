# 책나무 어휘 모바일 CBT

핸드폰에서 한 문제씩 푸는 순수 HTML 퀴즈입니다. **PWA**로 설치하면 인터넷 없이도 사용할 수 있습니다.

## GitHub Pages

배포 주소: https://wanzanggmail.github.io/booktree/

저장소 → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main** / **/(root)** → Save

## 로컬 실행

```bash
cd chaeknamu-cbt
npx --yes serve .
```

브라우저에서 안내된 주소로 접속한 뒤, **어휘골든벨** / **어휘사전** 중 하나를 고릅니다.

### 오프라인(PWA) 사용

1. **한 번**은 인터넷으로 페이지를 엽니다. (문제·정답이 기기에 캐시됩니다)
2. 핸드폰에서 **홈 화면에 추가 / 앱 설치**를 선택합니다.
3. 이후에는 설치한 아이콘으로 오프라인 실행이 가능합니다.

## 시험 구성

| 시험 | 설명 | 데이터 |
|------|------|--------|
| 어휘골든벨 | 학습지 45문항 (유형 혼합) | `data/goldenbell/` |
| 어휘사전 | 뜻을 보고 낱말 고르기 (4지선다) | `data/dictionary/` |

## 사용 팁

- 주관식에서 **Enter** → 다음 문제
- **정답확인**으로 문항별 채점
- 진행 내용은 시험별로 `localStorage`에 저장

## 어휘골든벨 답안 (`data/goldenbell/answers.json`)

직접 정답을 채워 넣습니다. 비어 있으면 미채점입니다.

| 유형 | 문항 | 답 형식 | 예시 |
|------|------|---------|------|
| 주관식 | 1–6, 40–42 | 문자열 | `"1": "염원"` |
| 선택 | 7–15, 28–34 | 보기와 **같은 문자열** | `"7": "선포하다"` |
| 연결 | 16–20, 35–39 | 고른 뜻/고사성어 문자열 | |
| ○/△ | 21–26 | `"○"` 또는 `"△"` | |
| 복수 | 27 | 문자열 배열 | `"27": ["A", "C"]` |
| 예문 | 43–45 | `null` (자동 채점 없음) | |

## PWA 파일

- `manifest.webmanifest` — 앱 이름·아이콘
- `sw.js` — 오프라인 캐시
- `icons/` — 앱 아이콘
