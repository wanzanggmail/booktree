# 책나무 어휘 모바일 CBT

핸드폰에서 한 문제씩 푸는 순수 HTML 퀴즈입니다. **PWA**로 설치하면 인터넷 없이도 사용할 수 있습니다.

## GitHub Pages

배포 주소: https://wanzanggmail.github.io/booktree/

저장소 → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main** / **/(root)** → Save

## 로컬 실행

```bash
cd chaeknamu-cbt
npx --yes serve .
```

브라우저에서 안내된 주소로 접속한 뒤, **어휘골든벨** / **어휘사전** 중 하나를 고릅니다.

### 오프라인(PWA) 사용

1. **한 번**은 인터넷으로 페이지를 엽니다. (문제·정답이 기기에 캐시됩니다)
2. 핸드폰에서 **홈 화면에 추가 / 앱 설치**를 선택합니다.
3. 이후에는 설치한 아이콘으로 오프라인 실행이 가능합니다.

## 시험 구성

| 시험 | 설명 | 데이터 |
|------|------|--------|
| 어휘골든벨 | 학습지 45문항 (유형 혼합) | `data/goldenbell/` |

## 사용 팁

- 주관식에서 **Enter** → 다음 문제
- **정답확인**으로 문항별 채점
- 진행 내용은 시험별로 `localStorage`에 저장

## 영어 영영풀이 (Lesson 5–8)

첨부 학습지 8장의 어휘 103개를 모두 수록했습니다. Lesson 5는 28개, Lesson 6은 24개,
Lesson 7은 26개, Lesson 8은 25개입니다.

- 영영풀이를 보고 영어 단어를 답합니다.
- 주관식 41문항 / 5지선다 62문항으로 약 4:6 비율입니다. 주관식은 공백 없는 3~6자 단어로 구성합니다.
- 시작할 때 전체 문항을 무작위로 섞으며, 이어 풀기는 저장된 순서를 유지합니다.
- 시작 화면에서 Lesson 5–8 중 출제할 단원을 선택할 수 있습니다. 선택은 이어 풀기에 저장됩니다.
- 정답확인 시 정답 단어와 한글 뜻을 표시합니다.
- 각 문항의 **예문** 버튼으로 영어 예문과 한글 해석을 펼치거나 접습니다.
- `plant`, `post`는 원문의 두 가지 뜻과 예문을 모두 보존했습니다.
- 영어 답안은 대소문자와 앞뒤 공백을 구분하지 않습니다.

데이터는 `data/english-lessons/questions.json`과 `answers.json`에 있습니다.
문항의 `source`에는 첨부 파일명, Lesson, 원문 번호, 교과서 쪽수를 기록했습니다.

## 어휘골든벨 답안 (`data/goldenbell/answers.json`)

직접 정답을 채워 넣습니다. 비어 있으면 미채점입니다.

| 유형 | 문항 | 답 형식 | 예시 |
|------|------|---------|------|
| 주관식 | 1–6, 40–42 | 문자열 | `"1": "염원"` |
| 선택 | 7–15, 28–34 | 보기와 **같은 문자열** | `"7": "선포하다"` |
| 연결 | 16–20, 35–39 | 고른 뜻/고사성어 문자열 | |
| ○/△ | 21–26 | `"○"` 또는 `"△"` | |
| 복수 | 27 | 문자열 배열 | `"27": ["A", "C"]` |
| 예문 | 43–45 | `null` (자동 채점 없음) | |
